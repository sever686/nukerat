# 概览

Dockview 工作区。面板在此挂载、打开和关闭。

## 目录

- `/agent`：AI 智能体聊天
- `/credentials`：凭据列表（添加、编辑、查看、移除）
- `/explorer`：所选主机的文件浏览器
- `/file_server`：团队服务器文件服务器（上传、下载、重命名、删除）
- `/graphs`：入口点与会话图谱
- `/keylogger`：键盘记录条目
- `/ns_debugger`：NukeScript 调试器输出
- `/process`：所选主机的进程列表
- `/screenshot`：所选主机的截图
- `/sessions`：会话列表
- `/terminal`：主机终端
