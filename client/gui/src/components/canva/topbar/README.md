# 概览

Canva 外壳的主菜单栏。工作区标签、快捷键以及浮动顶栏面板（服务器、监听器、植入体等）的入口都在这里。

## 目录

- `/about`：关于面板
- `/agents`：LLM 智能体配置
- `/downloads`：栏内的下载活动控制
- `/implants`：Stageless 与 loader 植入体构建器
- `/iocs`：IOC 列表与过滤器
- `/listeners`：监听器创建与管理 UI
- `/logs`：团队服务器日志查看器
- `/network`：端口转发与 SOCKS UI
- `/nukescripts`：NukeScript 编辑器与校验 UI
- `/queue`：命令队列面板
- `/reports`：报告创建与查看
- `/servers`：已保存的团队服务器连接
