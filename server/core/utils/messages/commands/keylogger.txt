关于
    运行后台线程，监视用户按下的按键。

用法：
    keylogger <start|stop> [--method <method>] [--delay <ms>]

参数：
    --method            boardstate 或 keystate。Windows 上默认 boardstate。
    --delay             仅 boardstate 模式的轮询间隔（毫秒）。默认 50。

模式：
start               开始后台按键捕获。
stop                停止工作线程并刷新待处理的按键。

示例：
    keylogger start --method boardstate --delay 100
    keylogger start --method keystate
    keylogger stop

NUKERAT 选项：
-w <秒数>       等待超时的最大时间
-bg             后台运行，不等待输出

示例：
    keylogger -bg start --method boardstate
