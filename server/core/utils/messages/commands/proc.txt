关于
    进程查看与控制。仅限 Windows。

用法：
    proc <info|privileges|kill|suspend|resume> [flags]

参数：
    --pid               目标进程。proc info 默认针对植入体。
    --name              proc privileges 使用的权限名称（例如 SeDebugPrivilege）。
    -st                 on 或 off，用于启用或禁用该权限。

模式：
info                当前进程或 --pid 指定进程的摘要。
info modules        已加载模块列表。
info privileges     已打开进程的令牌权限。
info full           摘要、权限、额外详情与模块。
privileges          仅在植入体进程上启用或禁用权限。不接受 --pid。
kill                终止目标 PID。不能终止植入体自身。
suspend             挂起目标 PID。不能挂起植入体自身。
resume              恢复已挂起的 PID。

示例：
    proc info
    proc info modules
    proc info --pid 1234
    proc info --pid 1234 privileges
    proc privileges --name SeDebugPrivilege -st on
    proc kill --pid 5678

NUKERAT 选项：
-w <秒数>       等待超时的最大时间
-bg             后台运行，不等待输出

示例：
    proc -w 60 info full
