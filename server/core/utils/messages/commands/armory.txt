关于
    下载、更新或移除 NukeRat 军械库工具。

用法：
    armory [install|remove|update] [<tool>]

参数：
    <tool>              列表中的军械库命令名称（位于 install 或
                        remove 之后的位置参数）。

模式：
armory              列出工具及简短说明。
install             将载荷文件下载到服务器军械库目录。
install all         从发行包下载所有军械库工具。
remove              删除该工具已下载的文件。
update              更新军械库索引文件。

示例：
    armory
    armory install all
    armory install <tool>
    armory remove <tool>
    armory update <tool>
