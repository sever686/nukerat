关于
    以两种模式之一截取目标机器屏幕：单次截图或循环截图。

用法：
    screenshot [start|stop] [--delay <seconds>]

参数：
    --delay             screenshot start 的循环间隔（秒）。默认 2。
    -d                  --delay 的短形式。

模式：
screenshot          立即截图一次。
start               后台循环截图。
stop                结束循环。

示例：
    screenshot
    screenshot start --delay 15
    screenshot stop

NUKERAT 选项：
-w <秒数>       等待超时的最大时间
-bg             后台运行，不等待输出

示例：
    screenshot -w 60 start --delay 10
