关于
    尝试使用不同方法提升到 NT AUTHORITY\SYSTEM。使用与 migrate 相同的载荷（编译时生成的植入体 shellc
    ode）。仅限 Windows。

用法：
    getsystem [--method <method>] [--sacrifice <path>]

参数：
    --method            inject、token 或 com。默认 inject。
    --sacrifice         为 token 或 com 注入宿主派生的可执行文件。
    --path              --sacrifice 在植入体上的别名。

示例：
    getsystem
    getsystem --method inject
    getsystem --method token --sacrifice C:\Windows\System32\mspaint.exe
    getsystem --method com --sacrifice C:\Windows\System32\notepad.exe

NUKERAT 选项：
-w <秒数>       等待超时的最大时间
-bg             后台运行，不等待输出

示例：
    getsystem -w 120 --method token
