关于
    (linux) Http get download.

用法：
    bof-lin-wget --- <url> [output]

参数：
    url                 URL to download
    output              Output file

示例：
    bof-lin-wget --- <url>

NUKERAT 选项：
    -w <秒数>       等待超时的最大时间
    -bg             后台运行，不等待输出

    示例：
    bof-lin-wget -w 60 --- <url>
