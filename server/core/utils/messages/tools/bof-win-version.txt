关于
    Queries the registry and system APIs to provide a concise but detailed overview of the
    Windows installation.

用法：
    bof-win-version

示例：
    bof-win-version

NUKERAT 选项：
    -w <秒数>       等待超时的最大时间
    -bg             后台运行，不等待输出

    示例：
    bof-win-version -w 60
    bof-win-version -bg
