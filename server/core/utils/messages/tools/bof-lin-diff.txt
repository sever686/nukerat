关于
    (linux) Compare two files.

用法：
    bof-lin-diff --- <file1> <file2>

参数：
    file1               First file
    file2               Second file

示例：
    bof-lin-diff --- <file1> <file2>

NUKERAT 选项：
    -w <秒数>       等待超时的最大时间
    -bg             后台运行，不等待输出

    示例：
    bof-lin-diff -w 60 --- <file1> <file2>
