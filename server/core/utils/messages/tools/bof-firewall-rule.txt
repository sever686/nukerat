关于
    Add, remove, or query Windows Firewall rules via the COM API (INetFwPolicy2) without
    spawning netsh.exe or cmd.exe. Useful for pivoting inside networks.

用法：
    bof-firewall-rule --- <subcommand> [arguments]

SUB命令：
    add <name> <dir> <action> <protocol> [localport] [remoteport] [profile]
    remove <name>
    query <name>
    list

PARAMETER VALUES:
    dir                 in or out
    action              allow or block
    protocol            tcp, udp, or any
    profile             domain, private, public, or all (default all)

示例：
    bof-firewall-rule --- add pivot in allow tcp 4444
    bof-firewall-rule --- query pivot
    bof-firewall-rule --- list
    bof-firewall-rule --- remove pivot

NUKERAT 选项：
    -w <秒数>       等待超时的最大时间
    -bg             后台运行，不等待输出

    示例：
    bof-firewall-rule -w 60 --- add pivot in allow tcp 4444
