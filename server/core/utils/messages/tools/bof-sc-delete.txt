关于
    Deletes an existing Windows service.

用法：
    bof-sc-delete --- <SVCNAME> [HOSTNAME]

参数：

    SVCNAME    Service name

    HOSTNAME   Optional remote host

示例：

    bof-sc-delete --- MySvc

NUKERAT 选项：
    -w <秒数>       等待超时的最大时间
    -bg             后台运行，不等待输出

    示例：
    bof-sc-delete -w 60 --- MySvc
