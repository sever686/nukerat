关于
    Change a user password via kpasswd.
用法：
    bof-changepw --- /ticket:BASE64 /new:PASSWORD [/dc:DC] [/targetuser:USER] [/targetdomain:DOMAIN]

示例：
    bof-changepw --- /ticket:BASE64 /new:NewP@ss123

NUKERAT 选项：
    -w <秒数>       等待超时的最大时间
    -bg             后台运行，不等待输出

    示例：
    bof-changepw -w 60 --- /ticket:BASE64 /new:NewP@ss123
