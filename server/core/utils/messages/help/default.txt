-------------------------------------------------------------------------------------------------------------------------
注入
-------------------------------------------------------------------------------------------------------------------------

    migrate       migrate 4919 [--alloc <mode>]                        将植入体 shellcode 注入进程

    spawn         spawn -t cmd.exe --- <args>                          派生进程并捕获输出
                  spawn suspend -t C:\Windows\System32\notepad.exe     创建挂起进程（不恢复）

    inj           inj shellcode -f file.bin -p 2300 --- <args>         将 shellcode 注入进程
                  inj dll-reflective -f file.dll -p 2300               将反射 DLL 注入进程
                  inj donut -f file -p 2300 --- <args>                 通过 donut 注入多种类型的载荷

    --alloc       --alloc section                                      使用 section 分配
                  --alloc stomping [--stomp-dll "name.dll"]            使用模块践踏分配
                  [!] 可用于 inj 与 migrate

    --encoder     --encoder sgn                                        使用 sgn 编码器
                  [!] inj 仅支持 donut/shellcode

-------------------------------------------------------------------------------------------------------------------------
进程
-------------------------------------------------------------------------------------------------------------------------

    proc          proc info                                                       当前进程摘要
                  proc info [modules|privileges|full]                             显示指定进程信息
                  proc info --pid <pid> privileges                                进程的权限列表
                  proc info --pid <pid>                                           按 PID 查看进程摘要
                  proc privileges --name SeDebugPrivilege -st [on|off]            启用或禁用权限
                  proc [kill|suspend|resume] --pid <pid>                          按 PID 修改进程状态

    tokens        tokens                                                          当前令牌
                  tokens grab --pid 1000                                          从进程抓取令牌到保险库
                  tokens list                                                     列出已保存的保险库令牌
                  tokens impersonate --id 0                                       模拟保险库中的令牌
                  tokens remove --id 0 [--all]                                    移除保险库令牌
                  tokens forge --domain name --user jhon --pass 123456            创建伪造的登录会话
                  tokens revert                                                   停止模拟（RevertToSelf）

    runas         runas --domain name -u jhon -p 123 --path cmd.exe --- <args>    以其他用户身份执行命令

-------------------------------------------------------------------------------------------------------------------------
横向移动
-------------------------------------------------------------------------------------------------------------------------

    relay         relay                                                                                显示中继
                  relay create -c tcp -l 8888 -t [implant|server]://10.1.1.5:9090  [--tls]             创建 TCP 中继
                  relay create -c smb -l 445 -t [implant|server]://10.1.1.5:9090 --pipe test [--tls]   创建 SMB 中继
                  relay delete --id 445                                                                按 ID 移除中继

    [!] SOCKS5 与端口转发选项位于菜单：NukeRat > Network。
