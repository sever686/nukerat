-------------------------------------------------------------------------------------------------------------------------
通用
-------------------------------------------------------------------------------------------------------------------------

    (命令)        (用法)                                                   （描述）

    help          help                                                     显示此帮助信息
                  help arp                                                 显示命令详情与示例
                  help -os [linux|mac]                                     显示当前操作系统兼容的命令

    config        config                                                   查看植入体配置
    delay         delay 4                                                  设置植入体延迟（秒）

    kill          kill                                                     终止植入体进程

    tasks         tasks                                                    显示运行中的任务 ID
                  tasks kill 3912                                          按 ID 终止运行中的任务

-------------------------------------------------------------------------------------------------------------------------
文件系统
-------------------------------------------------------------------------------------------------------------------------

    pwd           pwd                                                      显示当前目录
    cd            cd /home/user                                            切换目录
    ls            ls /etc                                                  列出文件和目录
    cat           cat /etc/hosts                                           显示文件内容
    preview       preview /etc/hosts --size-limit 4096                       读取文件开头字节
    fileinfo      fileinfo /etc/hosts                                        文件元数据（大小、时间、属性）
    acl           acl /etc/hosts                                           路径的所有者、组与 ACL 条目

    echo          echo hello world                                         输出文本

    cp            cp /tmp/a.txt /tmp/b.txt                                 复制文件
    mv            mv /tmp/a /tmp/b                                         移动文件
    rm            rm /tmp/a.txt                                             删除文件
    ren           ren /tmp/a /tmp/b                                        重命名文件
    mkdir         mkdir /tmp/newfolder                                     创建目录
    rmdir         rmdir /tmp/newfolder                                     删除目录
    attrib        attrib /tmp/a.txt                                        查看或修改文件属性
    set           set                                                      查看或设置环境变量
    download      download -f C:/file.exe -o file.exe                      从目标下载文件
    search        search --path /Users --content password                  搜索文件内容

-------------------------------------------------------------------------------------------------------------------------
信息收集
-------------------------------------------------------------------------------------------------------------------------

    whoami        whoami                                                   当前用户信息
    env           env                                                      列出所有环境变量
    tasklist      tasklist ROOT\CIMV2                                      通过 WMI 获取运行中的进程
    ifconfig      ifconfig                                                 网络适配器配置
    netstat       netstat TCP                                              活动连接
    portscan      portscan --target 192.168.1.100                          在植入体上执行端口扫描

-------------------------------------------------------------------------------------------------------------------------
执行
-------------------------------------------------------------------------------------------------------------------------

    shell         shell whoami                                             执行 shell 命令
    spawn         spawn -t /bin/sh --- -c whoami                           派生新进程
    load-dylib    load-dylib -f file.dylib                                 将动态库加载到内存

-------------------------------------------------------------------------------------------------------------------------
横向移动
-------------------------------------------------------------------------------------------------------------------------

    relay         relay                                                                         显示中继
                  relay create -c tcp -l 8888 -t [implant|server]://10.1.1.5:9090  [--tls]      创建 TCP 中继
                  relay delete --id 445                                                         按 ID 移除中继

    [!] SOCKS5 与端口转发选项位于菜单：NukeRat > Network。

-------------------------------------------------------------------------------------------------------------------------
修饰符
-------------------------------------------------------------------------------------------------------------------------

    -bg           shell -bg dir                                            后台运行，不等待输出
    -w / --wait   shell -w 30 ping 127.0.0.1 -n 10                         设置自定义最大等待时间（秒）
    prefix        prefix                                                   显示当前命令前缀
                  prefix powershell                                        设置附加到每条命令前的固定前缀
                  prefix clear                                             清除当前前缀
