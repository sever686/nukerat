关于
    Tool included with Microsoft SQL that loads SQL Server cmdlts. A
    replacement for sqlps.exe. Successor to sqlps.exe in SQL Server
    2016+. LOLBAS documents executing PowerShell command.

用法：
    SQLToolsPS.exe -noprofile -command Start-Process {PATH:.exe}

示例：
    SQLToolsPS.exe -noprofile -command Start-Process {PATH:.exe}

NUKERAT 选项：
    -w <秒数>       等待超时的最大时间
    -bg             后台运行，不等待输出

    示例：
    SQLToolsPS.exe -noprofile -command Start-Process {PATH:.exe}
