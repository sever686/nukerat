关于
    Default apps settings executable.
    UAC bypass when ms-settings Shell\open\command is hijacked to run
    elevated code without a prompt.

用法：
    ComputerDefaults.exe

示例：
    ComputerDefaults.exe

NUKERAT 选项：
    -w <秒数>       等待超时的最大时间
    -bg             后台运行，不等待输出

    示例：
    ComputerDefaults.exe
