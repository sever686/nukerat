关于
    Binary file used for compile vbs code. LOLBAS documents compile
    attacker code on system. Bypass defensive counter measures.

用法：
    vbc.exe /target:exe {PATH_ABSOLUTE:.vb}
    vbc -reference:Microsoft.VisualBasic.dll {PATH_ABSOLUTE:.vb}

示例：
    vbc.exe /target:exe {PATH_ABSOLUTE:.vb}
    vbc -reference:Microsoft.VisualBasic.dll {PATH_ABSOLUTE:.vb}

    -w <秒数>       等待超时的最大时间
    -bg             后台运行，不等待输出
